360 Video Converter · UI 重设计提案（4 选 1）

信息架构与功能保持不变，仅替换视觉世界。每套方案均为 1440×900 批量转换界面的完整效果图，点击 HTML 文件预览。
方案 A · 石墨驾驶舱DARK
近黑石墨底 + 翡翠单强调。等宽数字、发丝线分隔、密度拉满的专业监控台。 编码参数与系统监控并列为主角，信息一目了然，适合长时间盯进度的重负载场景。
深色密度 8等宽数字8px 圆角翡翠 #34d399
方案 B · 晨纸工作室LIGHT
冷调纸白 + 墨黑文字 + 电光钴蓝。疏朗留白、软圆角卡片、胶囊导航，安静轻盈不抢戏。 适合白天办公环境、偏好浅色界面的日常使用场景。
浅色密度 4疏朗留白14px 圆角钴蓝 #1f5eff
方案 C · 工业终端DARK
炭黑直角 + 琥珀单强调 + 等宽字体主导。ASCII 进度条、键值点线对齐、[F1] 快捷键标注， 终端语汇的硬核工程工具。参数即命令行，信息密度最高。
深色密度 9直角 0pxmono-first琥珀 #f0a832
方案 D · 深海钴蓝DARK
深海蓝灰 + 钴蓝/青双色渐变层级 + 悬浮胶囊导航与操作坞。卡片化分组、16px 大圆角、 辉光层级，现代 Pro App 语汇（Linear/Raycast 一族但蓝色系独占）。
深色密度 616px 大圆角胶囊导航钴蓝→青
通用承诺（四套共同遵守）：信息架构与交互流程不变（六模式页签 / 三栏工作台 / 底部动作栏）； 无 emoji 图标（统一 SVG 描边图标）；无紫粉渐变；无 AI 模板味文案；字色对比满足 WCAG AA； 兼容 1440×900 与 1024×640 最小窗口；所有数字/文件大小/时间戳统一等宽字体渲染。

选定方案后：先出该方案的全模式（6 个页签）+ 弹窗/空态/错误态完整设计稿供二轮确认，确认后再进入开发 （CSS 令牌层重写，交互逻辑零改动，全部 9 道门禁回归）。
