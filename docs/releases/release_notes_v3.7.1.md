# v3.7.1 — 元数据批量列表 UI 修复

## 修复内容

### BUG-M11: 元数据批量执行列表不可见

**问题**: v3.7.0 实现的元数据批量执行列表使用了单选按钮（"单个文件" / "批量（递归扫描）"）切换模式，用户无法发现批量列表入口，也看不到"加入批量列表"按钮。

**根因**: UI 设计与批量转换工具的风格不一致。转换工具使用始终可见的"加入批量队列"按钮 + 任务列表表格，而元数据工具使用了隐藏在单选按钮后的模式切换，用户难以发现。

**修复**:
- 移除单选按钮模式切换（"单个文件" / "批量（递归扫描）"）
- 添加醒目的"📋 加入批量列表"按钮，与文件输入框并排
- 批量执行列表表格始终可见，不再隐藏
- 保留扫描目录作为批量导入的替代方式
- 统一输出目录输入框（留空 = 原地修改），适用于单个文件和批量处理
- 当批量列表有选中文件时处理批量；列表为空时处理输入框中的单个文件

### 界面变化

| v3.7.0 | v3.7.1 |
|--------|--------|
| 单选按钮切换 single/batch 模式 | 移除单选按钮 |
| 批量列表隐藏在 batch 模式后 | 批量列表始终可见 |
| 无"加入批量列表"按钮 | 文件输入框旁有醒目按钮 |
| 单文件/批量分别有输出设置 | 统一输出目录输入框 |

## 文件变更
- `static/index.html`: 重构元数据工具文件输入区域
- `VERSION`: 3.7.0 → 3.7.1
