# v3.13.15 — 主功能模块切换标签吸顶冻结

## 问题

页面纵向滚动时，顶部六个功能模块切换标签随内容一起滚走，切到长页面（如元数据报告）后想切回其他模块必须先滚回顶部。

## 改动

- 新增 `.mode-tabs-bar` 外层容器承载 `position: sticky; top: 0`，**标签栏吸顶冻结**，不受纵向滚动影响；`z-index: 20`（高于内容与表头 sticky，低于弹窗 100 / 下拉 200）。
- 外层承载 sticky 而非直接给 `.mode-tabs` 加sticky，是为了**保留已确认的胶囊导航外观**（全宽不透明条包裹胶囊），同时避免内容从标签与内容之间的缝隙透出。
- `.app` 顶部内边距转移到 `.header`（`padding: 0 20px 20px` + `header padding-top: 20px`），静止态视觉间距不变，但标签栏吸顶时紧贴视口顶部、无 20px 漏缝。
- 右侧「实时监控」列（`.ws-col-sticky`）吸顶位置由 `top: 12px` 调整为 `top: 100px`，**让开标签栏**（实测标签栏高 89.8px，留 10px 呼吸）；`max-height` 同步扣除顶部标签栏与底部吸底动作栏，避免监控内容被遮挡或伸进动作栏。
