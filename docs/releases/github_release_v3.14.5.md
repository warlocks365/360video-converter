# v3.14.5 — 彻底修复 AI 助手面板 X 关闭后无法重开（重要：请升级）

## 问题

v3.14.4 的面板修复不彻底：点击面板右上角 X 后，「AI 助手」按钮仍然无法重新打开面板。

## 真实根因（组件源码取证）

AI 助手组件的面板 X 按钮在**空闲状态下执行的是"销毁"而不是"隐藏"**——整个助手实例连同面板节点被永久移除。v3.14.4 的修复只覆盖了"隐藏"路径，对"销毁"路径无效：销毁后的实例再点按钮，操作的是一个已死对象，永远无法恢复。

## 修复

- 打开按钮前先检查助手实例是否已被销毁，**已销毁则自动重建一个全新实例**（沿用当前设置）；
- 挂接组件的销毁回调，实例销毁时同步清理应用侧引用（双保险）；
- 面板可见性判定增加"节点是否仍在页面上"校验，杜绝样式残留误判。

## 验证

打包版真实浏览器内核实机：**真实点击面板内 X 按钮** → 确认销毁全链生效（面板节点从页面移除）→ 再点「AI 助手」按钮 → **成功重开**；二次销毁重建仍稳定（8/8）。契约级双场景回归 13/13（X 销毁重开 / 折叠隐藏重开 / 任务运行中 X=停止的保护语义 / 三连切换）。全部质量门禁与既有回归零劣化。

## 说明

v3.14.4 存在同样缺陷，已标记废弃。v3.14.3 用户同样建议升级到本版。
