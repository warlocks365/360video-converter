# v3.13.18 — 元数据工具三项修复

## 修复内容

### 1. 恢复「开始批量列队执行」按钮

元数据工具此前只有一个「应用元数据」按钮，其文案在「应用元数据 · N 项」与「按界面设置应用」之间切换，队列执行与界面单文件执行混在同一条路径里，职责不清、且在无待转换项且输入框为空时被禁用、点击无反应。

现拆分为两个职责独立的按钮：

- **应用元数据（当前文件）**：只处理「视频文件」输入框中的单个文件，文案恒定不被队列状态改写；
- **开始批量列队执行**：只负责队列执行，取「已勾选且未完成」的项按列队顺序执行、忽略界面设置。四种禁用成因（全执行中 / 未勾选 / 列队为空 / 勾选全完成）分别给出对应的状态提示，并显示待转换项数。

两者仅在元数据模式可见，互斥显示。

### 2. 「按界面设置应用」改为设置同步器

此前该功能实际语义是「忽略队列、按界面设置执行单个文件」，与预期不符。现改为：把界面各设置项**统一写入所有已勾选的列队项**（覆盖各自原设置），**不改动各项的输出目录**，**不启动任何转换**。

执行中（processing）的列队项会被跳过并明确提示跳过数量；成功、部分跳过、未勾选、异常四条路径均有明确提示，不会静默失败。

### 3. 拍摄位置 GPS 增强（列队编辑 / 元数据工具 / 其他含GPS 的标签页）

三处标签页（`p_` / `m_` / `me_` 前缀）统一提供：

- **地图选点**：在地图上选取坐标并写入当前拍摄位置（含经纬度、名称、地址）。其中列队编辑弹窗此前**完全没有地图选点入口**，本次一并补齐；
- **一键复制**：将该条目下所有拍摄位置数据序列化为 **JSON 文本**写入剪贴板，含 schema、坐标、地点名、详细地址、来源与更新时间；
- **一键粘贴**：从剪贴板读取 JSON，先做格式校验（合法 JSON、对象类型、经纬度为合法数字且范围合法）再写入，失败时明确区分原因（剪贴板为空 / 非合法 JSON / 缺少字段 / 坐标超范围），**不会部分写入**；
- 三处标签页的 JSON 字段命名完全一致，可跨标签页复制粘贴。

## 附带修复

- **后端功能门口径修正**：`/api/apply_metadata` 原先只校验顶层 `params`，导致「界面开关全关、但列队各项自带功能开关」这一合法批量提交被拒（用户只能看到一句英文后端错误，批量流程无法执行）。现改为顶层开启**或**任一项的独立参数开启即放行，空提交拦截保持不变；
- **任务运行中禁止重复提交**：新按钮纳入任务期禁用集合，并在执行入口增加运行中早退，杜绝「后端起了孤儿作业、界面却显示待转换、文件被重复处理」；
- **门禁 08 新增产物覆盖断言**：此前该门禁对「exe 漏打最新前端资源」零覆盖——exe 时间戳早于源码时依然全绿，反而掩盖了产物没更新的事实。现断言首页必须包含本版新增的功能标识。
