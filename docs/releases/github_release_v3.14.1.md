# v3.14.1 — AI 助手对抗验收修复轮

本版是 v3.14.0（page-agent AI 助手集成）的**安全与正确性修复版**，不新增功能。独立 QA 对抗验收揪出 2 项 P1 缺陷 + 3 项 advisory，全部修复并复验通过。

## 修复项

### B1 中继路径白名单：松散变体穿透（P1，安全）
`/api/agent_relay` 原先用 `normpath` 归一化后比较，`/chat//completions`、`/chat/./completions`、`/chat/completions/` 一类松散变体会被「归一化放行」，且以非规范形态转发到上游。
**修复**：改为**精确串相等**——`path != '/chat/completions'` 一律 400。比归一化更严更简，`../` 穿透、`//`、`./`、尾斜杠、大小写、查询串、无前导斜杠全部天然拒绝，转发串即校验串，语义无歧义。
**验证**：echo 回显靶实测三个松散变体全部 400、上游零命中。

### B2 权限门链式双重确认（P1，UX）
`startConversion` 的 vr3d 分支内部调用同为包装函数的 `startVR3D`，两层各自弹确认，standard 档会连弹两窗。
**修复**：加同步链深度标记 `_gatedChainDepth`，链深 > 0 时内层继承外层决策、不再重复弹。
**验证**：vr3d 模式 agent 触发转码，confirm 弹 **1 次**、日志记录「链式调用继承外层决策」、内层真函数正常执行。

### A1 启动期恢复 AI 助手入口
此前按钮显隐只在打开设置时赋值，`agent_enabled=true` 后重启/刷新按钮仍隐藏（违背设置字面语义）。
**修复**：boot 期读到设置即调 `vcRestoreAgentUI`——不发请求、不加载 vendor（「默认关零注入」不破）。

### A2 权限门名单对齐能力分级表
补 `saveReport`（写盘下载）、`exportReportLog`（写盘下载）、`openExternalUrl`（起系统浏览器）三个 L2 副作用函数，11→14 项——此前 agent 可无确认触发它们。

### A3 非 ASCII 密钥错误脱敏
API Key 含非 ASCII 字符时，中继会抛 `latin-1` 编码内部异常并 502 回显 Python 异常原文。
**修复**：入口校验可打印 ASCII，非法即 400 中文提示，不透出内部细节。
