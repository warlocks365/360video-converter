# v3.13.16 — 元数据报告内容可自由选择复制

## 问题

元数据报告里的元数据**完全无法用鼠标选中复制**（实测拖选 `rangeCount=0`）。

## 根因

`user-select` 计算值为 `none` 并沿Blink 的继承语义级联到全应用。DevTools `CSS.getMatchedStylesForNode` 显示存在一条**后加载样式表**里的 `body { user-select: none }`，按加载顺序压过 `app.css`。属第三方全局重置（Leaflet 的 `user-select` 规则均带作用域限定，非此来源）。

## 修复

`app.css` 新增「文本可选区」规则，用 `!important` 显式开启全应用文本选择（覆盖第三方全局重置的正规用法），并把交互控件排除在外：

- **可自由选择**：报告全部字段（含文件名与完整路径）、系统监控、任务日志、表单输入值等只读内容；
- **保持禁选**：按钮、页签、开关、复选框、下拉项、徽章芯片、字段标签——拖过它们不产生选区，避免误操作，也不选中「时长」这类与值无关的噪声标签。
