# v3.13.14 — 元数据工具：加入批量列队 / 列队输出目录 / 列队优先执行 / 日期浏览回填

## 一、加入批量列队

动作栏新增「加入批量列队」按钮（紧邻「应用元数据」），把当前界面已配置的全部参数**完整快照**加入元数据列队：入队即固化输出位置（快照/全局/原地三态），之后界面改动不再影响已入队项。去重按路径规范化比对，命中时提示所在序号并闪烁该行。Toast 直接说明输出结果。

## 二、列队编辑补齐输出目录

列队每项的编辑弹窗新增**输出位置三态**（全局 / 快照 / 原地）与输出目录输入框。原先输出目录只能在全局设置，无法按项调整。三态用「图标 + 文案 + 描边样式」三重编码，不依赖颜色单独传达。

## 三、应用元数据改为列队优先

原逻辑「勾选项优先、否则界面单文件」改为：列队存在待转换任务时忽略界面设置、按列队顺序执行；仅当无待执行项才回落到界面设置。待执行项 = `已勾选 && 状态≠已完成`。已完成项**保留在列队**并标记，可经「重跑」改回待转换；按钮文案随队列状态切换（`应用元数据 · N 项` / `按界面设置应用`），徽标同步显示待转换/已完成/失败计数。

## 四、手动指定日期支持浏览回填

`单文件 / 合并 / 批量 / 元数据工具` 四个模块的「手动指定日期」输入框右侧新增「读创建时间」按钮：弹出文件对话框，读取所选文件的**文件系统创建时间**并回填。回填值直接可用，不做时区二次加工。**任何失败路径都不清空或修改用户已输入的日期**。
