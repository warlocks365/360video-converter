# v3.13.9 — 元数据报告：多条件筛选叠加 + 值集合下拉 + 加入队列目标可选

## 一、多条件筛选叠加

报告筛选从单条件升级为**多条件行叠加（AND）**：每行 = 筛选字段下拉 + 值下拉 + 删除按钮；「添加筛选条件」可加任意多行，行间与逻辑叠加。字段分六组（容器/视频流/音频流/球面元数据/时间/位置 GPS）。

## 二、筛选值改为值集合下拉

值控件不再需要手动输入：切换字段时，值下拉自动填充**当前报告数据在该字段上的去重值集合**（按 zh-CN 排序），从中直接选择即可（精确匹配，大小写不敏感）。布尔字段（moov 状态/是否 GSpherical）保持 是/否 下拉。

## 三、加入队列目标可选

选择栏新增队列目标下拉：

- **加入批量转换队列**（原行为：makeTask + 当前参数快照）；
- **加入元数据批量队列**（新增）：按元数据批量列表条目结构写入（自动启用日期/位置/球面的探测建议），入队后逐个自动探测元数据，并自动切换到元数据工具模式。
