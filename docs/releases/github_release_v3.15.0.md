# v3.15.0 — AI 助手 CLI 指令集：从「模拟点击」到「原生指令」

本版让页内 AI 助手摆脱逐控件模拟操作的慢路径：新增一套 39 条 `vc` 命令的 CLI 指令集与页内命令控制台。助手用「输入命令 → 执行 → 读结构化 JSON」三步完成原本需要十几二十次模拟点击的任务（批量转码、配置查询、任务轮询、失败恢复），更快、更准、可验证。

设计契约：`docs/design/v3150_cli_command_set.md`（含三通道权衡与三阶段迁移方案）。

## 新增能力

### 命令控制台（设置启用 AI 助手后可见）
- 命令输入框 + 执行按钮 + 结果 JSON 块 + 待确认操作条 + 常驻手册摘要；
- 助手可直接操作（输入框是其原生支持的文本写入面），**你也可以手动使用**；
- 执行 `vc help` 获取完整命令手册（9 组 39 条，含参数与示例）。

### 指令集覆盖
- **任务**：`vc job start-convert / start-vr3d / apply-metadata / status / log / pause / resume / skip-item / add-items`
- **探测**：`vc probe file / source / metadata / date / fs-time / insv-pair / vr3d-alignment`（不执行任何转换即可读回码率、GPS、拍摄时间）
- **文件**：`vc file scan / browse / drives`（目录扫描直接返回结构化清单）
- **配置/预设/任务文件**：`vc config show / codecs / codec-check / test-ffmpeg / test-encoder`、`vc preset list / save`、`vc task save / list`
- **地理/报告/系统**：`vc geo search / reverse`、`vc report generate / save / diagnostic`、`vc sys version / monitor`

### 统一协议
- 所有命令返回同一 JSON 信封 `{ok, code, data, error{kind,message,hint}, meta}`；
- 14 个稳定错误码（参数错/校验失败/作业占用/无权限/恒禁/后端故障…），每个都附带「下一步该怎么做」的处置提示；
- **任务轮询增量游标**：`vc job status --since-seq` 每次只返回新日志行，长任务不重复消耗；
- **幂等提交**：`--request-id` 保证助手重试时不会重复建任务；
- **单活动互斥**：命令层统一补齐（此前并发防护只在界面层），防止并发提交互踩输出文件。

## 权限与安全（本版核心升级）

- 权限裁决**从界面层收口到后端内核**：功能表 E 的 L0-L3 分级现在对 AI 助手强制生效，无论指令从控制台还是直接 HTTP 发出，结果一致——界面层防护不再是唯一防线；
- **恒禁区**：修改应用设置（防助手自我改写模型端点）、删除预设、原地覆盖源文件（输出=输入自动识别拒绝）、取消运行中任务；
- 「标准」权限档下，每个会产生新文件的任务**只请求一次确认**（旧路径是每一步都可能弹窗），确认条展示完整操作摘要；确认按钮加入人性化延迟——助手瞬时自动批准会被拒绝，保留人类阅读时间；
- CLI 全程零对外网络请求（进程内转发），运行态经真实浏览器内核取证确认。
