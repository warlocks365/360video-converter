# 360 Video Converter v3.14.7

修复版本：元数据工具筛选按钮点击无反应（v3.14.6 交付缺陷）。

## 问题与根因

v3.14.6 新增的批量列队筛选功能中，「筛选」与「添加条件」两个按钮**点击无任何反应**。

根因：这两个按钮只有元素 id，没有绑定任何事件（无 onclick、无 data-action、无脚本监听）——筛选栏开关与添加条件行的功能函数虽已实现，但事件链断裂，点击无法到达函数。

如实说明验证盲区：v3.14.6 的两套验收只断言了"按钮 DOM 在位"，并直接修改内部筛选状态驱动渲染，**从未真实点击过按钮**，因此接线断裂未被测出。

## 修复内容

- 两个按钮补上 `data-action` 接线，注册进中央事件派发器；
- 新增两套**真实点击**回归套件堵住该盲区：
  - jsdom 全链路（dispatchEvent 真实鼠标事件）：13/13；
  - 打包 exe 实机（CDP 驱动真实 click，含"点在按钮内 SVG 图标上"的冒泡场景）：10/10。

## 升级建议

v3.14.6 用户请升级：筛选功能本体（引擎、AND 叠加、导入导出、GPS 选点修复）均正常，仅入口按钮不可用；本版本只补接线，无其他行为变更。
