# v3.14.3 — 修复地图选点不显示（瓦片改同源后端中继）

## 问题（用户实报）

打开「地图选点」后地图区域全灰、无瓦片显示。

## 根因（CDP 取证）

- 地图初始化完全正常（容器尺寸、Leaflet 实例、瓦片槽位均就绪）；
- 但全部瓦片请求到 `*.tile.openstreetmap.org` 均被 `net::ERR_CONNECTION_RESET`；
- 同页面其他外网站点（baidu/github/aliyun）全部正常、同机命令行直连 OSM 也正常——
  即干扰**只作用于浏览器网络栈到 OSM 瓦片域的连接**（按域名特征重置），
  属外部网络条件变化，**非代码回归**（地图模块自 v3.13.18 起零改动）。

## 修复

沿用本项目既有先例（外部 API 一律经本地后端代理，地理编码/逆地理同法）：

- 新增瓦片中继端点：后端直连 OSM 取瓦片（本机已实证可达），绕开被干扰的浏览器直连路径；
- **本地磁盘缓存**：瓦片落盘缓存（约 60MB 上限、惰性淘汰），重复浏览零上游请求，符合 OSM 瓦片使用政策；
- **合规**：携带规范 User-Agent、保留 OSM 版权署名、坐标边界校验；
- 前端瓦片源改指同源中继，7 天浏览器缓存头。

## 验证（真实浏览器内核取证）

- 修复前：瓦片渲染 0/10，全部连接重置；
- 修复后（打包版 exe 实测）：**瓦片渲染 10/10**，全部经同源中继，直连 OSM 域请求 0，失败 0；
- 中继性能：首次回源约 0.5s，缓存命中约 2ms；
- 新增门禁 11 静态锁定该架构（防未来改回直连）；门禁 01–11 全绿，既有回归零劣化。
