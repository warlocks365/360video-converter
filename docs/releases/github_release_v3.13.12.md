# v3.13.12 — UI 重设计：深海钴蓝主题（方案 D 实施）

## 概述

按用户选定的**方案 D「深海钴蓝」**完成全局视觉重设计。信息架构与交互逻辑零改动，通过 CSS 令牌覆盖层 + 组件精修实现：

- **深海径向渐变底**：`radial-gradient` 深海蓝灰底色（#0d1220 基底）；
- **钴蓝→青双色品牌渐变**：主按钮、进度条、监控条、Logo 字标统一 `linear-gradient(135deg, #4d8dff, #37d6c3)`；
- **模式导航胶囊化**：六模式页签改为胶囊分段导航，激活态钴蓝填充 + 辉光；
- **卡片化面板**：16px 大圆角、渐变面板底、深海投影；
- **P0 合规**：六个模式页签的 emoji 图标全部替换为内联 SVG 描边图标（P0 禁 emoji 规则）；
- **浅色伴生主题**：主题切换保留，浅色为同一钴蓝家族的伴生配色。

## 附加修复

- `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 由整体覆盖改为**合并**（用户附加参数此前被静默丢弃）；
- 新增诊断开关 `360VC_REMOTE_DEBUGGING_PORT`：设置后开启 WebView2 CDP 远程调试（`Runtime.exceptionThrown` 捕获前端未捕获异常）；
- 默认主题改为深色（深海钴蓝为默认视觉）。
