# v3.15.1 — 修复面板关闭后无法重开；AI 助手默认改用 CLI 指令

## 修复一：点面板右上角 X 后，「AI 助手」再也打不开（用户实报）

**根因**：面板的 X 按钮由组件内部直接隐藏面板，不通知外部——外部的"面板是否打开"状态卡死在"已打开"，再点顶部「AI 助手」按钮永远走"关闭"分支，表现为按钮失效。

**修复**：切换逻辑改为探测面板**真实可见性**（以 DOM 为准），不再依赖状态旗标。实机验证：X 关闭 → 再点按钮 → 正常重新打开，连续开关切换稳定。

## 修复二：AI 助手仍默认模拟鼠标点击，而非 CLI 指令（用户实报）

**根因**：v3.15.0 建成了 CLI 指令通道，但没有把「本应用存在命令控制台、何时优先用命令」的策略告知助手——助手默认按通用网页操作模式逐控件点击。

**修复**：向助手的模型请求注入「CLI 优先编排指令」（以叠加方式注入，不破坏厂商内置提示词），内容包括：

- **优先级铁律**：凡能用 `vc` 命令完成的操作必须用命令，禁止逐控件模拟点击；
- **操作方式**：命令写入「命令控制台」输入框 → 点执行 → 读结果 JSON；
- **自取手册**：先发 `vc help` 获取全量命令与参数；
- **编排五拍**：探测 → 校验 → 提交（带幂等 ID）→ 增量轮询 → 分支处置；
- **权限约定**：确认条必须等待人类点击（助手自动秒批为违规）；被禁区拒绝（改设置/删预设/原地覆盖）立即上报用户、不重试。

**实机验证**（打包版 + 真实模型）：抓取出站 LLM 请求体，确认注入块（含命令控制台说明与优先级铁律）完整到达模型。
