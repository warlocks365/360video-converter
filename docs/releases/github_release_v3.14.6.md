# v3.14.6 — 元数据工具三功能：GPS 选点修复 + 叠加筛选 + 状态导入导出

## 一、批量编辑 GPS 选点修复（点 X/选点/回写/批量规则）

**问题根因（一因三症状）**：地图弹窗与编辑窗口同为同层级浮层且地图在文档流中更靠前——地图被编辑窗口压在**下层**；用户点"地图"实际点穿到编辑窗口遮罩，触发其"点遮罩关闭"逻辑，编辑窗口关闭且编辑目标被复位，于是：地图看不见、选点时编辑窗口消失、坐标没有回写。

**修复**：地图弹窗层级提升至独立层（z-index 130，高于常规弹窗 100、低于下拉 200），地图始终位于所有编辑面之上。

**批量赋值规则（新增「应用到全部勾选项」按钮，编辑窗口页脚）**：
- 把当前编辑的设置（含 GPS）**同值复制**到所有勾选项——每个勾选项写入完全相同的经纬度/地点/地址；
- 不做逐条差异化、不做坐标偏移或平均；
- 执行中的项自动跳过（参数不可改写）；
- 不启动任何转换。

## 二、批量列表筛选（与元数据报告同一引擎，AND 叠加）

批量列表新增筛选栏（工具栏「筛选」按钮开关），与元数据报告共用同一筛选引擎，支持多条件 AND 叠加：

| 维度 | 字段 | 匹配方式 |
|---|---|---|
| 项目状态 | 转换状态、文件大小 | 下拉精确选择 |
| 任务开关 | 全景元数据、日期写入、GPS 写入 | 是/否 |
| 全景细分 | pano 类型（360/180）、立体模式 | 下拉精确选择 |
| 字符串 | 文件名、拍摄地址、详细地址、文件名日期、设定日期 | 包含 / 不包含 / 为空 / 非空 + 自由文本 |
| 输出归属 | 输出模式（全局/快照/原地） | 下拉精确选择 |

**与勾选和批量编辑的协同**：
- 「全选」只选中当前筛选可见的条目（隐藏项不动，与报告侧一致）；
- 「全不选」清空全部勾选；
- 「应用到全部勾选项」作用于勾选项集合；
- 工具栏徽标显示「筛选后 N / 共 M」。

元数据报告侧同步增强：拍摄地址、详细地址、文件名从"精确下拉"升级为**自由文本包含/不包含**匹配（原有空值/非空判断保留）。旧版保存的筛选条件自动迁移，行为不变。

## 三、批量列表状态 JSON 导入/导出

- **导出**（工具栏「导出状态」）：调用系统标准保存对话框写入 `.json`，内容包括全部条目的勾选状态、编辑设置（GPS/日期/全景）、输出模式、当前筛选条件；
- **导入**（工具栏「导入状态」）：调用系统标准打开对话框读取并完整还原——筛选条件、勾选状态、批量编辑设置；导入前如当前列队非空会明确提示将替换；
- **异常处理**：文件不是合法 JSON、不是本工具导出的文件、版本高于当前程序、条目缺路径——分别给出可读原因；无效条目逐条计数跳过，未知筛选字段按版本差异丢弃并计数告知，绝不静默半读入。
