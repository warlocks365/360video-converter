# v3.7.2 — 元数据批量列表简化

## 修复内容

### BUG-M12: 元数据工具移除目录扫描功能

v3.7.1 的元数据工具保留了"扫描目录（批量导入）"功能，与用户预期不符。
元数据工具的批量场景是：逐个打开文件 → 设置元数据 → 加入列表，而非目录遍历。

v3.7.2 修改：
- 移除"扫描目录"输入区域和 `scanMetaDirectory()` 函数
- 批量列表工具栏新增"添加文件"按钮（直接打开文件选择对话框添加到列表）
- 更新操作提示文字，明确工作流程：选择文件 → 设置元数据 → 加入批量列表 → 批量处理

## 文件变更
- `static/index.html` — 移除扫描目录 HTML 和 JS，添加工具栏"添加文件"按钮
- `VERSION` — 3.7.1 → 3.7.2
