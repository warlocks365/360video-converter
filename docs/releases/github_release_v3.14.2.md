# v3.14.2 — AI 助手 Base URL 容错修复

## 问题（用户实报）

在「设置 → AI 助手」的 Base URL 输入框中粘贴**完整聊天端点**（如 `http://127.0.0.1:8888/v1/chat/completions`）后，AI 助手执行任务报 `InvokeError: HTTP 404: File Not Found` 并重试失败。

**根因**：中继按设计把白名单路径 `/chat/completions` 拼接到 Base URL 之后，完整端点被拼成双路径 `…/chat/completions/chat/completions`，本地推理服务对未知路由返回 404。设置项本身（密钥、模型名）无误。

## 修复

- **中继容错**：Base URL 尾段为 `/chat/completions` 时自动剥离后再拼接——粘贴完整地址或根地址均可正常工作；
- **保存归一**：设置保存时把完整端点归一为根地址，输入框所见即所得；
- **提示明确**：输入框占位文案说明"粘完整地址也会自动归一"。

**已安装 v3.14.0/v3.14.1 的用户**：无需重装——中继每次请求读取配置，本次修复已随配置归一化对旧版本生效；升级到 v3.14.2 可获得输入框层面的容错与提示。

## 验证

- 用报错场景的原始输入（完整端点 + 真实密钥 + 模型名）经中继打真实推理端点：HTTP 200，模型正常回复；
- 新增回归断言：保存归一（S4.6）+ 中继剥离后上游实收规范单路径（B6b，echo 靶字节级证明无双路径）；套件 59/59；
- 门禁 01–10 全绿（07=37/37、08=20/20）；既有回归零劣化。
