# v3.14.4 — 修复 AI 助手面板关闭后无法重新打开（v3.15.x 已废弃回退）

## 版本说明

应开发者要求，**v3.15.0 / v3.15.1 引入的「CLI 指令集」功能方向作废并已完整回退**。本版本以 **v3.14.3 为基线**，仅包含下述面板修复——功能面（AI 助手行为、界面布局、后端接口）与 v3.14.3 完全一致，无命令控制台卡片。

## 修复：点面板右上角 X 后，「AI 助手」按钮再也打不开面板（用户实报）

**根因**：AI 助手面板右上角的 X 由组件内部直接隐藏面板 DOM，不通知外部程序——应用记录的「面板已打开」状态卡在"已打开"，之后再点顶部「AI 助手」按钮永远执行"关闭"动作，表现为按钮失效。

**修复**：切换按钮改为每次读取面板**真实可见性**（以 DOM 实际渲染状态为准），不再依赖内部状态记录。
