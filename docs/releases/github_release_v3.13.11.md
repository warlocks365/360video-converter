# v3.13.11 — 元数据报告筛选：值下拉新增「（空值）」选项

## 功能

元数据读取（报告）模式的多条件筛选中，值下拉**固定提供「（空值）」选项**——选择后即可筛出**该元数据项不具备内容**的文件（如无地名、无拍摄时间、无地址的素材），无需手动输入。

- 位置：报告筛选每一行的值下拉，紧随「（全部）」之后；
- 匹配语义：该字段值为空（含纯空白）的条目；
- 与其他条件 AND 叠加（如「location_name=（空值）」+「编码器=h264」→ 无地名且 H.264 编码的素材）；
- 布尔字段（moov 状态/是否 GSpherical）恒有 是/否，不提供空值选项。
