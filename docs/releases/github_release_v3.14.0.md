# v3.14.0 — 集成页内 AI 助手（page-agent）

本版为工具新增「自然语言操控」能力：集成 [alibaba/page-agent](https://github.com/alibaba/page-agent)（MIT），在设置里配置一个 OpenAI 兼容的模型端点后，可用一句话驱动全部现有功能——视频转换、参数配置、批量处理、元数据队列、复杂多步任务编排。

## 新增能力

### AI 助手设置组（设置弹窗内）
参考主流大模型接入形态，新增以下配置项：
- **模型端点 Base URL**（OpenAI 兼容）：支持本机 llama.cpp / 局域网推理服务 / 云端 API 三类；
- **模型名称**、**API Key**（端点需要时填写）；
- **思考模式**：默认 / 开启 / 关闭（经请求体透传给模型）；
- **推理深度**：自动 / 低 / 中 / 高 / 最高 / 极限；
- **权限控制**：只读 / 标准 / 完全信任 三档；
- **执行参数**：温度、最大步数、步间隔。

功能开关默认关闭，纯转码用户零感知、体积零影响。

### 自然语言操控全流程
助手以纯文本方式读取界面并操作（无截图、无需多模态模型），可跨模式编排多步任务，例如「把这几段合并后按 H.265 转码，再给结果打上拍摄位置」——它会自行切换模式、填参数、入列队、触发执行。

## 安全与隐私设计（本版重点）

1. **本地化随包分发**：AI 引擎脚本打进安装包，禁用公网 CDN（离线可用；这是本项目既有约束）。
2. **零自动外联**：引擎以 `autoInit=false` 加载，**不会**自动连接任何默认/测试端点；只有在设置里配置了模型端点并主动打开助手后，才建立连接。运行时已用真实浏览器内核验证——加载引擎全过程零对外请求。
3. **密钥不出本机后端**：API Key 仅存本地设置文件；所有模型请求经应用内置的同源中继转发，浏览器/DOM/日志都拿不到明文，界面只回显掩码。
4. **权限门（函数包装）**：助手触发任何「会创建/覆盖文件」或「破坏性」动作（启动转码、取消任务、删除预设、清空列表等）都受三档权限约束——只读档一律拦截并中文提示，标准档逐项弹确认，且**用户手动操作完全不受影响**；修改应用设置属禁区，助手期间一律拦截（防止助手自我改写配置端点）。
5. **数据流向明示**：开启助手会把当前界面文本（含视频文件路径、参数值）发送到你配置的模型端点，设置面板已明确标注。
